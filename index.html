html-editor

把任意静态 HTML 变成浏览器里的 Word 式可视化编辑器

给一份静态 HTML 注入一段自包含编辑器，就能在浏览器里直接拖区块、改文字、调字体字号、 加粗/颜色/链接、换图、撤销重做；改完一键导出剥离了编辑器的干净 HTML。 零依赖、零构建、离线可用，不绑定任何 AI 宿主。

打开在线 Demo GitHub 仓库
  • 在线 Demo：点上面的按钮，直接体验拖拽 / 改字体 / 导出（就是 examples/demo.html 注入编辑器后的样子）。
  • 作为技能：复制进 agent 的技能目录（QoderWork / Claude Code / Codex / Cursor 等），说一句话就能触发。见 README.md、SKILL.md、AGENTS.md。
  • 作为命令行：pipx install . 后全局可用 html-editor 你的.html。
  • 作为 MCP server：pipx install '.[mcp]'，接进任意支持 MCP 的 agent（需 Python 3.10+）。
  • 纯手动：python3 assets/inject.py 你的.html，双击生成的副本即可，完全不用 AI。
